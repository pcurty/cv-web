# CV Web Terminal - Pierre Curty

Ce repo contient le code de mon CV interactif sous forme de terminal.

Petite précision importante : le dev web (HTML, CSS, JS) n'est pas ma spécialité. Mon domaine, c'est le développement logiciel, la logique et l'architecture (principalement C++ et Python). 

Comme je voulais un support original pour mes candidatures sans y passer des semaines au détriment de mes vrais projets logiciels, j'ai conçu ce CV web en m'aidant de l'IA. Le but de ce repo n'est pas de prouver que je suis un expert front-end, mais d'avoir un outil fonctionnel et d'être transparent sur mes méthodes de travail. Si vous cherchez un profil orienté logiciel ou back-end, vous êtes au bon endroit.

Structure des fichiers :
- index.html : le contenu de base du CV
- style.css : l'interface du terminal et le responsive
- script.js : l'animation de frappe au démarrage et le bouton de copie du mail
